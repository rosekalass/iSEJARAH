Tetapan Headcount Sejarah

Pilih kaedah pengiraan sasaran. Nilai OT1, OT2 dan ETR pada Prestasi Murid, Dashboard dan GPMP menggunakan kaedah yang sama.

KAEDAH 1
+
+
+
Kaedah 1: OT1 = MIN(TOV + increment OT1, 100) · OT2 = MIN(OT1 + increment OT2, 100) · ETR = MIN(OT2 + increment ETR, 100).

ETR = MIN(IF(TOV ≥ 90, TOV+2, IF(TOV ≥ 80, TOV+4, IF(TOV ≥ 70, TOV+6, IF(TOV ≥ 60, TOV+8, IF(TOV ≥ 40, TOV+10, TOV+10))))), 100)

OT1 = ROUNDUP(TOV + ((ETR − TOV) / 3), 0)

OT2 = ROUNDUP(TOV + (((ETR − TOV) × 2) / 3), 0)

Untuk TOV bawah 40, sistem meneruskan kenaikan +10 supaya sasaran ETR kekal tersedia. Semua nilai dihadkan antara 0 hingga 100.

Hard Reset Cache Tempatan

Admin sahaja. Memadam LocalStorage/cache pada pelayar ini. Data Supabase tidak dipadam.

Tindakan ini hanya memadam salinan/cache tempatan pada pelayar. Dalam mod Supabase, data production dalam Postgres kekal dan boleh ditarik semula selepas login.

Dalam production, tetapan sekolah hendaklah disimpan dalam Supabase dan perubahan hanya dibenarkan kepada peranan yang diberi kuasa. LocalStorage digunakan di sini hanya untuk prototaip Canvas.
